"# ONEM2M_IPE" 

##Compte rendu TP3 ( Eric Harkat, Olivier Durand, Raphael Betti)

Nous avons réussi toutes les étapes du TP, il reste à les intégrer dans notre projet IOT Aquarium.
La principale difficulté à été de comprendre la synthaxe utilisé par OneM2M pour la création de plugin, désormais nous sommes capable de créer notre propre IPE.

##Etape de création IPE
- Création de l'ACP 
- Création de deux application entity
- Création des containers, ce sont les senseurs qui auront les contents instances qui contiennent les données
- les addSensor sont les capteur qui envoient les données et les readSensor c'est l'IPE qui va chercher les données
- Ajout d'un capteur de test en plus de ce que demande le TP
